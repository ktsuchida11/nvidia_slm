# 手法選択の意思決定表 — タスク × データ × base強度（loop1-10実証）

学習手法は「何を変えたいか」ではなく「baseの現在地とデータの形」で決まる。
loop8/9/10 の失敗はすべてこの表を引かずに走った結果と後から説明できる。

## 役割分担（大原則）

| 手法 | 変えるもの | 効く条件 |
|---|---|---|
| **DAPT**（継続事前学習） | ドメイン分布への適応（文体・語彙・数値パターン） | 大量の生ドメインテキスト。**知識注入や指標ゲインは1epochでは起きない** |
| **SFT**（模倣学習） | 出力形式・タスクの型 | base が**できない**振る舞いを、**目標形式と一致するデモ**で教える |
| **GRPO**（強化学習） | 検証可能軸の仕上げ | プログラム採点可能 + base が**「時々正解」帯域** + 未見プロンプト + KLアンカー |

## 意思決定表

| baseの現在地（実測必須） | データの形 | 選ぶ手法 | 根拠ループ |
|---|---|---|---|
| タスクの形式ができない（schema崩れ等） | 目標形式と一致するデモ | **SFT** | loop1-7: analysis JSON で改善 |
| タスクの形式ができない | 形式不一致（冗長解説等）のデモしかない | **SFTするな**。教師で目標形式の簡潔デモを新規蒸留してから | loop9 r1: 0.78→0.16 に崩壊 |
| 新形式をSFTで足したいが既存タスクの形式も守りたい | — | **マージせずアダプタ切替**。狭い形式のSFTは LoRA・lr2e-5・2ep でも他タスク形式を壊す（loop13: 読解+5pp ↔ analysis −15pp）。配信をタスクで切り替えれば両立 | loop13: 形式退行はfull-param DAPT特有ではないと実測 |
| 「時々正解」帯域（exact 0.4-0.8目安） | 検証可能な採点器 + **学習未見**プロンプト | **GRPO**（KL必須） | loop9 r2: 帯域診断パス |
| ほぼ全問正解（暗記済み・0.9超） | SFTと同一プロンプト | **GRPOするな**（advantage=0で信号ゼロ） | loop8: 完全空振り |
| 既に強い（exact 0.7超）＋残りがハード問題 | — | **天井**。GRPOは fixed≈broken の入れ替えのみ | loop9 r2: net +1 |
| ドメイン知識が足りない（closed-book弱い） | 生ドメインコーパス1回露出 | **DAPT単発は不十分**。多epoch×パラフレーズ増幅 or DAPT→SFT連結。**先にRAGと費用対効果比較** | loop10: probe完全同点 |
| ドメイン知識が足りない ＋ 知識が文書として手元にある | 検索可能なコーパス | **RAG**（学習しない）。probe 0.0402→0.4724（11.8倍）を ~$12 で達成し、$300-550 のDAPT多epoch路線をクローズ | loop12: RAG圧勝 |
| RAGの誤答が検索律速（gold_in_ctx低い） | — | **k拡大よりrerank**（k0広取り→rerank→top5）。文脈は量より質: rerank top5 0.5879 > k10 0.5427。gold_in_k0_rate で天井を先に測る（k0圏外はrerankでは原理的に救えない→メタデータフィルタ等の検索前段へ） | loop14: probe 0.6332・変換効率91% |

## 判断手順（この順で）

1. **base実測**: 目標タスクの評価をbaseで走らせ、帯域（exact/scoreの分布）を確認する。
   これをせずに手法を選ばない（loop9はbase測定で「既に強い」と分かった時点でSFT不要が見えた）
2. **データ×目標形式の一致検査**: 学習データの回答形式が評価時の目標形式と一致しているか目視サンプル。
   「日本語として高品質」でも形式がズレていればSFTは**逆方向**へ動かす
3. **GRPOの3点セット**（欠けたら走らせない）: (a) 学習未見プロンプト (b) 連続部分点報酬
   （全成分二値はグループ内分散が出ない） (c) 「時々正解」帯域を狙った出題
4. **KL/参照ポリシーは検証可能GRPOで必須**: KLなしは fixed<broken のドリフト劣化
   （loop9: net −10 → KL0.02+lr1e-6 で net +1）。384GBホストなら常時有効でよい
5. **天井シグナルが出たら止める**: train reward 横ばい + fixed≈broken = そのタスク・その規模では頭打ち。
   タスクを変える（baseが弱い軸を選ぶ）か、reward軸を変える（簡潔さ・過程・忠実性）か、上流（データ/base）へ戻る

## DAPTで知識注入を狙う場合の前提（loop10の結論 → loop12で決着）

- 1epoch = 各事実1回露出では、held-out ppl が下がっても（−10.6%）closed-book で取り出せる知識は入らない（probe完全同点）
- 生テキスト学習は指示追従・形式遵守を侵食する（既存eval退行）→ DAPT→SFT連結で形式回復が標準構成
- **loop12で実測決着**: 同じprobe 199問がRAG（NIM埋め込み+top5文脈注入）で 0.0402→0.4724。コストは
  DAPT多epoch見積り$300-550に対しRAG実測~$12。**知識が文書として手元にあるならRAGが先で、DAPTは
  分布適応（文体・語彙）専用**。役割分担: 知識=RAG / 分布適応=DAPT / 形式=SFT / 仕上げ=GRPO
