## 4. 未解決点（P4 までに確定させる）

1. **64GB GPU で何が動くか** — loop13 実測では **9B LoRA・seq4096 は L40S 44GB×1 で OOM**、
   2GPU + TP=2 が必要だった。64GB 単体なら **seq2048 の LoRA SFT は現実的**、seq4096 は要検証。
   → 判定に必要な情報: **GPU の型番・枚数・VRAM 構成**（ユーザーに確認）
2. **蒸留（S2）のハンズオン方式** — 教師 API 課金と外部送信が伴う。選択肢:
   (a) 事前生成済みデータを配布して `distill-dry` で配管だけ体験
   (b) 各自の API キーで少量（数十件）だけ実行
   → コストと情報管理の観点から **(a) を基本、(b) は希望者のみ**を推奨
3. **ハンズオンの所要時間配分** — S1 クレンジングと S8 RAG は CPU で回るが、
   RAG は埋め込みが要る。**dummy 埋め込みでの配管体験**か **NIM 起動**かで難度が変わる
