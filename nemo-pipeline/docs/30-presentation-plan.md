## 4. 未解決点の決着

1. **64GB GPU で何が動くか** — **未確定（ユーザー確認待ち）**。判定に必要なのは
   **GPU の型番・枚数・VRAM 構成**。loop13 実測（9B LoRA seq4096 が L40S 44GB×1 で OOM、
   43.5GiB 使用 + 1.9GiB 要求 = **必要 ~45.4GB**）から、64GB 単体なら seq4096 も入る見込み。
   → 影響範囲は **ハンズオン Step 6 だけ**に隔離済み（`35-handson-plan.md` §4 に VRAM 別の分岐表）。
   確認できなければ seq2048（loop1-7 の実績設定）で回す
2. **蒸留（S2）のハンズオン方式** — **決着: (a) `distill-dry` で配管体験を基本**、
   実課金は講師判断の希望者のみ（`make distill N_ANALYSIS=10 N_GEN=5`・$1未満）。
   全員でのAPIキー配布と外部送信は避ける
3. **RAG は dummy 埋め込みか NIM か** — **決着: dummy 埋め込み**。
   `RAG_K` / `RERANK_K0` を変えると `gold_in_ctx_rate` が実際に動くので、
   **NIM なしでも「文脈は量より質」の体験は成立する**（実測で確認済み）
