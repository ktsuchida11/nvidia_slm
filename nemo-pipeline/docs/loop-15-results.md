## 3. 実機の罠（詳細は s7_guardrails/README.md・traps.md へ反映）

1. **思考モードで良性まで全ブロック（最重要）** — nemoguardrails は self-check の LLM 呼び出しに
   `chat_template_kwargs` も `max_tokens` も渡さない。Nemotron が既定の思考モードに入ると
   ①1問 = LLM 3回 × 長考でタイムアウト ②長い思考文中の "yes" を既定パーサ `is_content_safe` が
   拾って**良性まで全部ブロック**（実測: 「売上高はいくらですか」が拒否された）。
   対策 = `llm_proxy.py`（`make serve-llm-proxy`）を通り道に挟んで注入。
   loop8 の「学習と評価で思考設定を揃える」原則をレールにも適用したもの
2. **single_config_mode** — `config_id` は `--config` に渡したフォルダ名そのもの
3. **yaml の `${VAR}` は展開されない** — `render_config.py` で自前描画
4. **リクエスト形** — `model` 必須（欠くと 422）、config_id は `guardrails.config_id`（ネスト）
5. **応答形** — `choices[]`（OpenAI 互換）。garak の JSONPath を誤ると空文字を採点して静かに無意味な結果
6. **内部エラーは HTTP 200** — 素朴に判定すると「攻撃成功」に誤計上し防御率を過小評価。
   `errored` として隔離し、`errored > 0` の結果は採用しない
